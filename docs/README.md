# Dokumentasi CSIRT Pekanbaru

Direktori `docs/` menampung dokumentasi pendukung proyek. Gunakan bahasa Inggris untuk nama seluruh direktori di bawah `docs/`, termasuk subdirektori bertingkat. Letakkan dokumen Markdown tambahan dalam subdirektori sesuai topiknya; jangan menambahkan berkas Markdown lain sejajar dengan `docs/README.md`.

Untuk brief baru, disarankan memakai pola nama `yymmdd-<urutan harian>-nama-brief.md`, misalnya `261104-01-fondasi-domain.md`. Gunakan tanggal Asia/Jakarta, urutan harian minimal dua digit mulai `01` setiap tanggal baru, dan nama singkat dalam kebab-case. Pola ini merupakan rekomendasi, bukan kewajiban; nama lain yang lebih sesuai konteks tetap dapat digunakan, dan berkas existing tidak perlu diganti namanya.

## Keputusan dan Brief

- Catatan keputusan pengecualian disimpan di `decisions/` dengan format `docs/decisions/YYMMDD-NN-judul-singkat.md` (Asia/Jakarta) hanya saat memilih pengecualian terhadap keputusan/aturan pengguna. Ketentuan lengkap mengikuti [AGENTS.md](../AGENTS.md).
- Brief usulan dan kebutuhan baru disimpan di `briefs/` dengan format `docs/briefs/yymmdd-NN-judul-singkat.md`.
